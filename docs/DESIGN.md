# 设计与能力边界

五项理论保持完整：尊重与责任（阿德勒）→表达与核对（NVC）→动机支持（SDT）→环境调整（场域）→可执行计划（WOOP）。重要解释必须有事件依据、反证/缺口和验证点，不为套理论推断学生目的。

事实记录→相关历史→待核假设→学生行动与教师支持→真实回访→修正。教育支持L1/L2/L3不等于临床风险；次数不自动升为危机，AI周追踪不改教师关注等级。当前安全情况由真人核实；紧急危险先由现场成人和学校专业机制保护接力，不能等待命令行分析或归档。

原始描述不被AI字段覆盖。记录请求ID控制幂等，保存后读回并给回执；查询覆盖本生全部原始事件而非仅最近几条。内容哈希不是数字签名，不保证管理员以后不会修改库。AI上下文仍可能节选，节选有数量提示，不能据此声称历史不存在。回访反馈进入后续分析与报告资料。

默认无案例库，检索缺失时不注入案例；可自行建设合法、脱敏、人工审阅的案例资料，作者私人案例不提供。源代码中案例草稿功能仅为内部草稿能力，公开CLI不自动起草、汇集或发布学生案例。

未宣称具备：多人注册鉴权、跨学校SaaS、已接通的机器人、自动回访日期决策、AI心理诊断、商业生产安全认证、真实效果验证。共享服务器只能由可信授权操作人员使用；有同校多角色权限需求时需先建设权限和审计层。
